⚡ 왜 2GB 영상에서도 멈추지 않나요?

과거 비디오 전체를 재인코딩(합성)하던 무거운 렌더링 방식을 완전히 배제하고, 스피커 소음 없이 오디오 신호만 스마트 분리하여 자막 텍스트와 타임스탬프만 고속 추출하기 때문입니다. 멀티스레드 Web Worker로 백그라운드에서 추론하여 브라우저 화면이 절대 굳지 않습니다.

🚀 3가지 엔진 특징 안내

  • 기기 자체 AI (Whisper): 브라우저 캐시를 사용하여 외부 서버 전송 없이 100% 안전하게 구동.
  • 브라우저 고속 엔진: 크롬/엣지 음성인식 API를 활용하여 0초 만에 대기 없이 인식.
  • 초고속 Cloud API (Groq): 무료 Groq API 키를 입력하면 1시간(2GB) 분량도 단 3~5초 만에 Whisper Large 모델로 전체 추출!
