# 🎬 AutoSub KR - 대용량(2GB+) 동영상 자동 한국어 자막 추출기 (Zero-Key)

백엔드 서버(Node.js/Python/AWS 등) 전혀 없이, **GitHub Pages(깃허브 페이지)**를 통해 100% 무료로 배포하고 브라우저에서 바로 사용할 수 있는 **대용량 동영상 자동 한국어 자막 추출 웹 애플리케이션**입니다.

2GB 이상의 대용량 고화질 영상에서 발생하던 **브라우저 멈춤, OOM(메모리 부족) 크래시, 무한 대기 버그를 완벽하게 해결**하고, **자막 추출 및 실시간 편집에만 100% 집중**하여 초고속으로 작동합니다.

---

## ⚡ 왜 2GB 영상에서도 절대 멈추지 않는가? (핵심 해결 기술)

1. **무거운 비디오 재인코딩(합성) 원천 배제**:
   - 과거 브라우저 탭이 죽던 주원인이었던 "Canvas 렌더링 + 비디오 재인코딩"을 완전히 배제하고, **오직 오디오 파형과 자막 텍스트만 고속 추출**합니다.
2. **Web Worker 멀티스레드 AI 아키텍처**:
   - AI 추론(Transformers.js Whisper)을 메인 화면 스레드가 아닌 **독립된 백그라운드 Web Worker**에서 실행하여, 연산 중에도 화면 멈춤(Freezing)이나 "페이지가 응답하지 않습니다" 경고가 0% 발생합니다.
3. **스피커 무음 고속 오디오 분리 (Mute-Bug 완벽 해결)**:
   - Web Audio API 가상 라우팅을 통해 스피커 소음 없이 100% 깨끗한 음성을 **최대 4배속~8배속으로 초고속 분리**합니다.
4. **다국어 Whisper 정식 모델 적용**:
   - 기존 영문 전용 모델(`whisper-tiny.en`) 대신 **다국어 모델(`whisper-tiny`)**을 적용하여 한국어 대사를 깨짐 없이 정확하게 인식합니다.
5. **3중 하이브리드 엔진 지원**:
   - 🤖 **기기 자체 AI (Whisper)**: 서버 전송 없이 내 컴퓨터 브라우저에서 100% 프라이빗 처리.
   - ⚡ **브라우저 고속 엔진 (Web Speech API)**: 모델 다운로드 0MB! 크롬/엣지 내장 엔진으로 즉각 인식.
   - 🚀 **초고속 Cloud API (Groq Whisper)**: 무료 Groq API 키를 입력하면 **1시간(2GB) 영상도 단 3~5초 만에** Whisper-Large-v3로 초고속 전체 자막 추출!

## 🛠 주요 기능

- **다양한 자막 포맷 원클릭 내보내기**:
  - `.SRT` (유튜브, 프리미어 프로, 팟플레이어 표준 자막)
  - `.VTT` (웹 비디오 표준 WebVTT)
  - `.TXT` (대사 전문 스크립트 / 블로그 및 AI 요약용)
  - 클립보드 원클릭 전문 복사
- **인터랙티브 동영상 자막 편집기**:
  - 자막 타임코드를 클릭하면 해당 비디오 재생 위치로 즉각 점프.
  - 대사 오타 및 맞춤법 실시간 수정 (화면 자막 오버레이에 즉시 반영).
  - 자막 전체 싱크 일괄 조정 (`-0.5초` / `+0.5초`).
  - 자막 검색(필터링), 추가 및 삭제.
- **다국어 자동 번역 & 듀얼 자막**:
  - 외국어(영어, 일본어, 중국어 등) 영상의 경우 [한국어 자막] 또는 [원문+한국어 듀얼 자막] 지원.

## 🚀 3분 만에 GitHub Pages 무료 배포하기

### 1단계: GitHub 새 저장소(Repository) 만들기
1. [GitHub.com](https://github.com)에 로그인 후 우측 상단의 **[+] ➔ [New repository]**를 클릭합니다.
2. Repository name에 원하는 이름(예: `autosub-kr`)을 입력하고 **[Create repository]**를 누릅니다.

### 2단계: `index.html` 파일 업로드
1. 생성된 빈 저장소 화면에서 **"uploading an existing file"** 링크를 누릅니다.
2. 이 폴더에 있는 `index.html` 파일을 드래그해서 끌어다 놓습니다.
3. 아래쪽 녹색 **[Commit changes]** 버튼을 클릭합니다.

### 3단계: GitHub Pages 활성화
1. 저장소 상단 메뉴에서 **[Settings]** 탭을 클릭합니다.
2. 왼쪽 메뉴에서 **[Pages]**를 클릭합니다.
3. **Branch** 설정을 `None`에서 **`main`** (또는 `master`)으로 변경하고 **[Save]**를 누릅니다.

### 4단계: 접속 및 사용 🎉
- 약 1~2분 후 상단에 발급된 웹사이트 주소로 접속하면 스마트폰이나 PC 어디서나 100% 무료로 자막을 추출할 수 있습니다!
  - 주소 형식: `https://<내아이디>.github.io/<레포지토리이름>/`
