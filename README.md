# 🎬 AutoSub KR - 무료 동영상 자동 한국어 자막 생성기 (Zero-Key)

백엔드 서버(Node.js/Python/AWS 등) 전혀 없이, **GitHub Pages(깃허브 페이지)**를 통해 100% 무료로 배포하고 모바일/PC 브라우저에서 바로 사용할 수 있는 동영상 자동 한국어 자막 생성 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **완전 무키 (Zero-Key & Zero-Registration)**:
   - 사용자나 개발자가 API 키를 발급받거나 회원가입할 필요가 전혀 없습니다.
2. **모바일 최적화 (Mobile-First)**:
   - 스마트폰에서 대용량 영상을 그대로 전송하지 않고, **기기 자체(Web Audio API)에서 오디오만 1~2MB로 가볍게 압축 추출**하여 1초 만에 처리합니다.
3. **듀얼 AI 엔진 지원**:
   - **초고속 공용 AI 엔진**: 모바일 배터리/발열 없이 2~3초 만에 대사 추출 및 한국어 번역.
   - **기기 자체 Web AI (Transformers.js ONNX)**: 브라우저 내부 메모리에서 직접 Whisper AI 구동 (인터넷 없어도 작동).
4. **실시간 자막 편집기 & 타임라인**:
   - 오타나 인명/고유명사를 클릭 한 번으로 직접 수정 가능.
   - 타임코드를 클릭하면 해당 영상 시점으로 즉시 점프.
5. **자막 스타일 커스터마이징**:
   - 유튜브 옐로우, 넷플릭스 화이트, 시네마틱 반투명 박스 스타일 지원.
   - 자막 크기 조절 (작게 / 보통 / 크게).
6. **2가지 다운로드 옵션**:
   - **⚡ 1초 다운로드**: 모바일 및 비디오 플레이어용 표준 `.SRT` 자막 파일 다운로드.
   - **🎬 하드섭 비디오 합성**: 브라우저 Canvas + MediaRecorder를 통해 자막이 깔끔하게 새겨진 새 비디오 파일(`.mp4` / `.webm`) 다운로드.

## 🚀 3분 만에 GitHub Pages 무료 배포하기

### 1단계: GitHub 새 저장소(Repository) 만들기
1. [GitHub.com](https://github.com)에 로그인 후 우측 상단의 **[+] ➔ [New repository]**를 클릭합니다.
2. Repository name에 원하는 이름(예: `auto-sub` 또는 `video-subtitles`)을 적고 **[Create repository]**를 누릅니다.

### 2단계: `index.html` 파일 업로드
1. 생성된 빈 저장소 화면에서 **"uploading an existing file"** 링크를 누릅니다.
2. 이 폴더에 있는 `index.html` 파일을 드래그해서 끌어다 놓습니다.
3. 아래쪽 녹색 **[Commit changes]** 버튼을 클릭합니다.

### 3단계: GitHub Pages 켜기
1. 저장소 상단 메뉴에서 **[Settings]** 탭을 클릭합니다.
2. 왼쪽 메뉴에서 **[Pages]**를 클릭합니다.
3. **Branch** 설정을 `None`에서 **`main`** (또는 `master`)으로 변경하고, 우측 폴더는 `/ (root)` 상태 그대로 **[Save]** 버튼을 누릅니다.

### 4단계: 모바일/PC에서 접속하기 🎉
- 약 1~2분 후 새로고침하면 상단에 내 무료 웹사이트 링크가 나타납니다!
  - 주소 형식: `https://<내깃허브아이디>.github.io/<레포지토리이름>/`
- 이 링크를 스마트폰 카카오톡이나 브라우저에 입력하여 언제 어디서든 무료로 영상을 올리고 자막을 달 수 있습니다.
